# LinkThink 玲可

一个具备可视化、可追溯、可打断特性的 Agent 系统。

---

## 技术选型与核心理念

- **技术栈**：采用 TypeScript (TS)
- **开发模式**：核心功能自主开发（"手搓"）

---

## 特性&功能实现
- **基础功能**：实现常见 Agent 的标准功能
- **干预机制**：支持修改历史记录，并允许用户以较高的自由度切换或介入 Agent 的工作流程
- **可视化**：过程可见，非黑盒
- **可追溯**：所有操作均可回溯
- **可打断**：支持随时中断和干预
- **扩展性**：能力可以通过接入外部工具进行拓展
- **历史记录**：被中断的任务或内容也应当被记录在历史中

---


## 最终目标

- **愿景**：最终实现系统自我迭代（使用 LinkThink 修改自身源码）

---

## 开发计划

- **时间规划**：从现在（5/14/26）起至暑假前
- **学习节奏**：保持一天一章的进度
- **构建周期**：约一个月的系统构建时间
